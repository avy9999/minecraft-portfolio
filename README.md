# ⛏️ Minecraft Portfolio

An immersive **Minecraft-inspired 3D portfolio** built with modern web technologies.  
This project transforms a traditional portfolio into an interactive, game-like experience where users can explore a 3D world showcasing projects, skills, and personal information.

---

## 🌍 Live Demo

👉 https://avy-portfolio.vercel.app

---

## ✨ Features

- 🎮 Fully interactive Minecraft-style 3D environment  
- 🧭 Smooth first-person / orbit-style camera controls  
- 🧱 In-world project showcase system  
- 💡 Interactive objects using raycasting  
- 🎨 Custom 3D models and environment design  
- ⚡ Smooth animations and transitions  
- 📱 Responsive layout (best experienced on desktop)

---

## 🛠️ Tech Stack

- React.js  
- Three.js  
- React Three Fiber  
- @react-three/drei  
- Blender (3D modeling)  
- GSAP (animations)  
- SCSS

🚀 Getting Started

Follow these steps to run the project locally:

1. Clone the repository
```git clone https://github.com/avy9999/minecraft-portfolio```

2. Navigate into the project
```cd minecraft-portfolio```

3. Install dependencies
```npm install```

4. Start development server
```npm run dev```
